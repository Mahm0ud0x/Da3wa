# Upgrade Layletna — Premium Template Gallery, Live Preview & Invitation Opening Experience

Continue working on the existing Layletna website and improve the current implementation rather than rebuilding everything blindly.

The main goal of this update is to make the wedding invitations and template experience feel **premium, emotional, elegant, and production-quality**.

The most important parts of this task are:

1. Template gallery must appear immediately after the hero/welcome section.
2. Templates must look beautiful and varied.
3. Users must be able to preview exactly how a template would look as a real invitation before choosing it.
4. The invitation itself must have a beautiful opening animation.
5. Typography must be one of the strongest parts of the entire product.
6. The agent should create enough high-quality template designs and image assets to make the product feel like a real commercial wedding invitation platform.

---

# 1. IMPORTANT UX CHANGE — TEMPLATE GALLERY SHOULD APPEAR VERY EARLY

After the initial hero/welcome section, the next major section on the homepage should be:

# "اختار دعوتك"

Subtitle:

**"اختار التصميم اللي يشبه ليلتكم، وشوف دعوتك قبل ما تبدأ."**

This section should appear BEFORE long feature explanations.

The reason is simple:

The visual invitation is the strongest selling point.

The user should quickly see:

* Beautiful invitations
* Different styles
* What the final product looks like

Then they become interested in buying.

# 8. INVITATION OPENING ANIMATION

This is one of the most important visual features.

When a guest first opens an invitation, do not immediately show the full invitation.

Instead show a beautiful opening experience.

Example concept:

A digital wedding envelope.

Centered:

Elegant envelope / invitation cover

Text:

**أحمد & سلمى**

Below:

**دعوة خاصة**

Button:

**افتح الدعوة**

When the user clicks:

**افتح الدعوة**

play a beautiful animation.

Possible animation:

1. Envelope appears centered.
2. Envelope flap opens.
3. Invitation card slides upward.
4. Soft fade / blur transition.
5. Invitation expands into the full screen.
6. Hero section appears.
7. Background music can optionally begin if enabled.

The animation should feel:

* Elegant
* Smooth
* Emotional
* Premium
* Short

Target animation duration:

Approximately 1–2 seconds.

Do NOT create a childish or flashy animation.

Think:

**Luxury digital wedding invitation.**

# 11. IMPORTANT FONT RULE

Use high-quality fonts that properly support Arabic.

Do not use poor fonts.

Do not mix too many fonts.

Maximum:

2–3 font families per template.

The system should allow each template to define its own typography.

For example:

```ts
{
  headingFont,
  bodyFont,
  accentFont
}
```

Make typography data-driven.

---

# 12. TEMPLATE SYSTEM ARCHITECTURE

Do NOT build each invitation page from scratch.

Create a reusable invitation renderer.

Each template should define things such as:

```ts
{
  id,
  name,
  category,
  colors,
  fonts,
  heroStyle,
  envelopeStyle,
  layout,
  decorations,
  images,
  active,
  featured
}
```

The invitation renderer should use this configuration.

This will make it much easier to add new templates later.
