# Build a Frontend Prototype for "Layletna | ليلتنا"

Create a polished, modern frontend-only prototype for an Egyptian digital wedding invitation platform called:

**ليلتنا | Layletna**

Tagline:
**ليلتكم تبدأ من هنا.**

The goal is to create a realistic SaaS-style product demo that feels like a real startup, not a simple template website.

This is **frontend only** for now.
Do NOT implement a real backend, database, authentication, payment gateway, real messaging API, or real hosting logic.
Use realistic mock data and local state so the entire experience works as a clickable prototype.

Use the screenshots provided in the conversation as visual inspiration for the general business concept, but do NOT copy their design. The new product should feel significantly more modern, premium, clean, and user-friendly.

---

## 1. Product Positioning

Layletna is not just an invitation generator.

The product helps couples create and manage a digital wedding invitation and their guest experience.

The core idea is:

**Invitation + RSVP + Guest Management + Wedding Details**

The interface should make these things extremely easy even for clients who are not tech-savvy.

Avoid complicated dashboards and technical language.

The user should always understand:

1. What step they are on
2. What they should do next
3. What their invitation currently looks like

---

# 2. Target User

Primary audience:

* Egyptian couples
* Families planning weddings
* Users with limited technical experience
* Mostly mobile users
* Arabic-first experience

The interface should support **RTL Arabic** beautifully.

Use Arabic as the main UI language.

A small English language toggle can exist, but Arabic is the default.

---

# 3. Visual Direction

Create a premium wedding aesthetic.

Style:

* Elegant
* Minimal
* Modern luxury
* Warm
* Emotional
* Clean
* Spacious
* High-end

Avoid excessive:

* Gold gradients
* Hearts
* Glitter
* Huge decorative elements
* Old-fashioned wedding website aesthetics

Preferred visual system:

* Warm ivory / off-white backgrounds
* Charcoal / near-black text
* Subtle champagne/gold accents
* Soft beige tones
* Elegant serif typography for wedding names
* Clean Arabic sans-serif typography for UI
* Thin borders
* Large whitespace
* Soft shadows
* Very subtle animations

The website should feel closer to a premium modern SaaS product combined with luxury wedding branding.

# 11. Important UX Principle

The entire product should be designed for people who are NOT technical.

Never overwhelm the user.

Avoid complicated sidebars with 15 items.

Use a simple navigation structure:

الرئيسية
دعوتي
الضيوف
المشاركة
إعدادات

On mobile, use a simple bottom navigation where appropriate.

Always show the next recommended action.

For example:

**الخطوة التالية: أضف قائمة الضيوف**

**إضافة الضيوف**
